# MBTC: geographic representativeness of public *M. tuberculosis* genomes

Code and derived data for a study of the geographic representativeness of public *Mycobacterium tuberculosis* genomes (manuscript in preparation; the manuscript and figures will be added after publication). Source metadata: ENA/INSDC, WHO TB burden estimates, World Bank WDI, all retrieved 14 October 2026.

## Contents
- `scripts/` analysis pipeline (v2 download, v3 analysis, v4 robustness, v5 regression, v6 extended robustness, `export_clean_samples.py`)
- `data/*_out/` derived outputs of each step (country tables, sensitivity analyses, regression output, Monte Carlo, study bootstrap)
- `data/clean_samples/mtb_clean_samples.csv.gz` cleaned analysis unit (287,030 BioSamples: country, collection year, release year, study accession)
- `data/mycotb_pilot_out/who_tb_estimates.csv` WHO burden estimates used
- `paper/` figure and table code (`make_figures.py`, `make_tables.py`) and derived tables (CSV); figure images are regenerated by running the code

## Reproduce
Python 3.10+; `pip install -r requirements.txt`. Run from the repository root:
```
python3 scripts/mycotb_pilot.py        # optional, network, slow: re-downloads ENA/WHO metadata
python3 scripts/mycotb_analysis.py     # v3
python3 scripts/mycotb_robustness.py   # v4
python3 scripts/mycotb_regression.py   # v5 (downloads World Bank indicators with curl)
python3 scripts/mycotb_extended.py     # v6
python3 scripts/turkey_provenance.py
python3 scripts/export_clean_samples.py
python3 paper/make_tables.py && python3 paper/make_figures.py
```
The raw ENA table (`data/mycotb_pilot_out/mtb_read_runs_all.tsv`, 119 MB) is not stored in the repository; `mycotb_pilot.py` regenerates it (ENA contents change over time, so a re-download will not reproduce counts exactly). Set `MBTC_BASE` to use another data directory.
